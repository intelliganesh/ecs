# Calculations and transformations

The audit inventories 29 calculations and deterministic transformations. These cover actual payroll data, scheduling, mapping, filtering, file generation and delivery. The page implements no retirement age, savings, investment, withdrawal, pension/corpus, inflation, projection, or scenario calculations.

All branches below were checked in source. The existing job already displayed in the dashboard confirmed the rendered job metadata and presence of saved rules. Phase 1 did not execute a new calculation or report run. Unless a calculation explicitly says otherwise, the trigger is a manual or scheduled generation run.
