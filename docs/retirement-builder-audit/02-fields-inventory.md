# Retirement Builder field inventory

There are **45 distinct UI input definitions**. Ten dashboard filter controls are counted separately, repeating row inputs are counted once per definition, and the shared dropdown search is counted once. Drawn values, read-only table cells, and action buttons do not count as inputs. Payroll Company and Clients are mutually exclusive fields. An empty value means an empty string unless stated otherwise. Edit generally loads saved values. API-only inputs are listed separately.

Each row records the location, exact visible label or accessible name, control, default, required status, limits, validation, dependencies/visibility and what the input changes. Validation IDs link conceptually to [existing rules and gaps](05-validations-and-edge-cases.md). Source names in the last column refer to the full paths linked below.

## API-only / internal inputs

- `general.reportSource` accepts `csv` or `companyPayroll` and defaults to CSV in the request model. Fresh Add UI supplies payroll, and no source switch is rendered. Existing full-job reads derive source from query markers. `general.testfileName` and `general.selectedFile` are model fields. Neither drives job persistence. The UI stores the chosen file name in its session draft.
- `fileSettings.sortingOrder[].orderBy` is an optional integer-text priority from 0 to 2,147,483,647. Missing/empty ranks as 0; persistence renumbers sorted rows from 1. Legacy signed ranks are decoded. It has no direct form field.
- `queryConfiguration[]` has `recttype` (up to 10 characters), `query`, `conditions`, and `sortOrder` strings. Payroll templates and CSV sort metadata are regenerated on save. No form edits raw query text.
- The manual Run request can accept a raw comma-delimited CSV body (5 MiB cap) with `text/csv`; the Dashboard button sends an empty request body. Creation accepts an optional Idempotency-Key header (1–128 visible ASCII characters without space).
- Monthly day, monthly week number, day interval, and week interval are stored or read internally. The wizard exposes no controls for them. There is no date-range, amount, retirement-age, slider, radio button, or chart input in the flow.
