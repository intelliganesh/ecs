Test logs record sanitized input/response values and SQL assertions. Authentication secrets, production payroll, recipient mailboxes and message bodies are absent. The Template workbook was verified as a static download in T020.

## Request and response examples

- **Create/update persistence.** The payroll fixture saved mappings for H, D and T and corresponding `rjob_query` markers. `[Employee Count] = 1.01` and `ORDER BY [Company Name] ASC, [Pay Date] DESC` persisted in detail query metadata. The CSV sort fixture used `CSV_SORT` and stored positive sorting positions. `rjob.filetype` was checked as byte values 44, 124, 59, 32 and 9 for comma, pipe, semicolon, space and tab. [RET-T041](01-test-execution-report.md#ret-t041), [RET-T108](01-test-execution-report.md#ret-t108), [RET-T109](01-test-execution-report.md#ret-t109), [RET-T119](01-test-execution-report.md#ret-t119)
- **Run body limit.** A 5,242,880-byte text/csv fixture returned 200 and 59 rows. One extra byte returned 413. Binary media returned 415. The overall output limit was verified separately from request length. [RET-T130](01-test-execution-report.md#ret-t130), [RET-T154](01-test-execution-report.md#ret-t154)
- **Transactional output failure.** Injected a failure after output creation started. HTTP 500 included `The job could not be completed. No results were saved.` Zero output files and zero result rows remained. History recorded Failed. [RET-T157](01-test-execution-report.md#ret-t157)
- **Retry scopes.** Same payload/key in a single process yielded one job; a different payload with that key gave 409. Independent workers returned IDs 116 and 117 for the same key and payload. [RET-T112](01-test-execution-report.md#ret-t112), [RET-T113](01-test-execution-report.md#ret-t113)
- **Scheduling and email.** Triggered eligible scheduled jobs with a fixed clock. Verified repeat slot skip and zero-output marker, and used loopback SMTP transport for SSL/STARTTLS and recipient rejection. Manual Run emitted no mail in the isolated workflow.
