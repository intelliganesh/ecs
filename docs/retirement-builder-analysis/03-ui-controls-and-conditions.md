# Every UI control and condition

## Counting convention

This inventory contains **108 named feature control definitions**, including shell navigation, actions, generated-option and shared-search behavior. A repeatable mapping input, subscription input, table-row selector or download link counts once per definition, not once per current row. Ten dashboard filters and ten sort buttons are individually counted. The two alternative subscription selectors are both counted. Buttons repeated identically in a shared header are one shared definition. Each dropdown's generated options are represented by one shared option-action definition, not hundreds of separate controls. Login's 4 adjacent controls are documented below and excluded from the feature count.

There are **16 dropdown definitions**, **6 checkbox definitions**, **0 radio groups**, and **0 input-switch toggles** (sidebar/password visibility use buttons). Counts are reproducible from [inventory data](evidence/control-inventory.json). A live DOM count varies with row count, screen and menu state; it is not this total.
